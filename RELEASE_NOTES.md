**Download `Corel.exe`** and run it. It installs itself, adds Desktop and Start menu shortcuts, and opens. Coming from Roicon? Corel imports your experiences, schedules and Roblox sign-in on first start.

### Roicon is now Corel 2.0
A complete redesign into a workspace for Roblox development teams.

- **New name, logo and interface.** Dark by default, light theme, six accent colours, a collapsible sidebar, global search (Ctrl K) and keyboard shortcuts throughout.
- **Projects** for each experience, with a task board, bugs, scripts, publishing, analytics, members and activity in one place.
- **Publish** (the Roicon engine): countdown icons that switch on schedule, now with date presets, custom countdown steps and overlay art, update announcements with a preview, live step tracking and history your team can see.
- **Analytics:** visits, players online, favorites and rating over time, comparisons between experiences, and imported Creator Hub data for revenue, DAU, session time and retention.
- **Bugs:** severities, statuses, assignments, attachments, live comments and a bug dashboard.
- **Scripts:** a shared Luau library with a real code editor, version history and safe simultaneous editing.
- **Team collaboration:** invites, roles and permissions, presence, a live activity feed and notifications, all synced in real time between teammates.

Windows 10/11. Windows SmartScreen may warn because the app isn't code-signed yet: choose "More info" → "Run anyway".
