**Download `Roicon.exe`** and run it. No install or setup needed.

### What's new in 1.1.2
- **New countdown artwork.** The 12 hours, 6 hours, 3 hours and 1 hour timers now use hand-made hourglass overlays on a dimmed icon.
- Custom timers (any other length or text) still get an automatic countdown overlay, and you can always use your own PNG.

Windows 10/11. Windows SmartScreen may warn because the app isn't code-signed yet: choose "More info" → "Run anyway".
