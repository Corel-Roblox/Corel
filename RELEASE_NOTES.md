### What's new in 1.1.1
- **New countdown icon style.** The built-in timers now dim your icon and add a big white hourglass with bold "5 HOURS"-style text, like the countdown thumbnails you see on Roblox.
- **Emoji in game names fixed.** Names like "[❄️] Build a Snowman" no longer show a box.
- **12-hour time by default.** Times show as 6:00 PM, and the date picker has AM/PM buttons. Prefer 18:00? Turn on **24-hour time** in Settings.

Windows 10/11. Windows SmartScreen may warn because the app isn't code-signed yet: choose "More info" → "Run anyway".
