**Download `Roicon.exe`** and run it. It installs itself, adds a Desktop and Start menu shortcut, and opens. Already installed? It updates by itself.

### What's new in 1.5.0
- **Rounded window corners** on Windows 11, with a choice of Round, Small or Square.
- **Pick your accent colour**: Violet, Blue, Teal, Rose, Sunset or Graphite. The whole app changes to match.
- **Appearance settings**: background effects (Vivid, Subtle or Off), interface size (90% to 125%) and Reduce motion. Reduce motion turns on by itself if Windows' animation effects are off.
- **Quick appearance menu**: the new palette button in the title bar.
- **Keyboard shortcuts**: Ctrl+1/2/3 switch tabs, Ctrl+Up/Down switch experiences, Ctrl+N adds an experience, Ctrl+, opens Settings, Ctrl +/−/0 change the interface size. Tab moves between controls and shows a focus outline.
- **More polish**: a wave spreads from where you click a button, a soft light follows the cursor, and the window buttons fade smoothly.

Windows 10/11. Windows SmartScreen may warn because the app isn't code-signed yet: choose "More info" → "Run anyway".
