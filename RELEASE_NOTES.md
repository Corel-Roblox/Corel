**Download `Roicon.exe`** and run it. It installs itself, adds a Desktop and Start menu shortcut, and opens. Already installed? It updates by itself.

### What's new in 1.4.0
**The app now matches the website.**
- **Upload → Approval → Live progress on every step.** Dots fill in as each stage finishes, the current stage pulses, and failures show in red.
- **Steps timeline.** Steps sit on a line that fills smoothly up to where the countdown is right now. The live step glows green.
- **Setup progress.** When you plan an update, a bar shows Connect → Current icon → New icon → Update date → Ready.
- **Yellow-pink-purple colors.** The countdown and the welcome headline shimmer in an animated gradient, and section headings use warm gradient text.
- **Cursor glow.** A soft light follows your mouse inside cards.
- **Faint grid background and warmer lights.**
- **Page switching.** Pages fade and rise in gently.
- **Tab bar.** It's back to a compact style, with a softly tinted active tab that slides between tabs.
- **Smoother edges.** Rounded buttons and highlights no longer have jagged corners.

Windows 10/11. Windows SmartScreen may warn because the app isn't code-signed yet: choose "More info" → "Run anyway".
