**Download `Roicon.exe`** and run it. It installs itself, adds a Desktop and Start menu shortcut, and opens. Already installed? It updates by itself.

### What's new in 1.3.1
- **No more jumping when you switch pages.** Pages now fade in place instead of sliding.
- **Fixed the tab highlight.** The "ghost" under the Update / Timers / Settings buttons is gone. The label now lights up as the highlight slides onto it.
- **Sharper icons.** Game icons, timer previews and the logo are shrunk smoothly instead of looking pixelated.
- Softer glow under the main buttons.
