**Download `Roicon.exe`** and run it. It installs itself, adds a Desktop and Start menu shortcut, and opens. Already installed? It updates by itself.

### What's new in 1.4.1
- **Fixed the old icon sometimes showing.** Windows remembers icons by file path, so after an update the old icon could still appear in the taskbar, on shortcuts or in File Explorer. Roicon now rebuilds its shortcuts and refreshes Windows' icon cache after every install and update.

Windows 10/11. Windows SmartScreen may warn because the app isn't code-signed yet: choose "More info" → "Run anyway".
