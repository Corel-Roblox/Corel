**Download `Roicon.exe`** and run it. It installs itself, adds a Desktop and Start menu shortcut, and opens.

### What's new in 1.2.0
- **Installs itself.** Running the download puts Roicon in your user folder (no admin needed), adds a **Desktop shortcut** and a Start menu entry, and lists it in Settings → Apps so you can uninstall it.
- **Auto-updates.** Roicon checks for new releases and downloads them in the background. A "Restart" button appears at the top when an update is ready. If Roicon is running in the tray, it switches over on its own. You can turn this off in Account & settings.
- **Countdown overlays are centered** on the icon.
- Fixed the clipped corners on the "Update in" card.

Coming from 1.1.x? Download this version once. Auto-update takes over from here.

Windows 10/11. Windows SmartScreen may warn because the app isn't code-signed yet: choose "More info" → "Run anyway".
