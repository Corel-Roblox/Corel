Design system

Swiss-minimal. Dark-first. Dense.

The rules behind Corel’s look: one cube, one accent, two typefaces and a calm, dense interface built for long working sessions. Click any colour to copy it.

01 · Logo

The core block.

An isometric cube made of three faces, separated by thin gaps. It reads as a building block, a game world and the “core” of your workflow, and stays recognisable at 16 pixels.

Corel Wordmark: IBM Plex Sans SemiBold, −1% tracking, mark at 1.2× cap height with the gap equal to one face width. Keep clear space of half the mark on every side. Don’t recolour the faces, rotate the cube or add effects.
02 · Colour

One accent, neutral everywhere else.

Surfaces are near-black neutrals separated by hairline borders, not heavy shadows. Signal green marks actions, focus and live states. Text pairs meet WCAG AA contrast.

03 · Typography

Plex for people, Mono for machines.

IBM Plex Sans for the interface: precise, technical and very readable at small sizes. JetBrains Mono for code, IDs and numbers that need to line up.

04 · Components

Small, quiet, consistent.

Controls are 28–32 px tall with 6–8 px radii. Lucide icons at 14–16 px, 2 px stroke. Every interactive element has a hover state and a visible focus ring.

05 · Principles

How Corel decides.

Honest data

Missing data says “Not available”, never zero. Sample charts are labelled Demo data. A step is “live” only after Roblox confirms it.

Density with calm

Fit a working day on one screen with 8–32 px spacing, hairline borders and one accent colour, not cards, gradients and noise.

Motion means something

150–250 ms transitions for state changes and arrivals. Respect “reduce motion”, and never animate just to decorate.

Keyboard first

Every page is a G-shortcut away, Ctrl K finds anything, C creates what fits the page, and focus is always visible.

Never lose work

Saves can’t overwrite a teammate, drafts survive restarts, and every script version can be restored.

Accessible by default

AA contrast for text, labels on icon buttons, status shown by icon and text as well as colour, and line styles that tell chart series apart.
